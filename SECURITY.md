# Security

Please do not disclose suspected vulnerabilities in public issues. Use the private vulnerability reporting mechanism on the [GitHub repository](https://github.com/mlimarenko/grafana-problem-desk/security) if available. Do not include credentials or live sensitive data in a report; provide reproduction steps and a safe way to contact you.

If private reporting is unavailable, wait until a private contact channel is provided rather than publishing exploit details. See the [security guide](docs/en/SECURITY.md) for deployment considerations.
