# Разработка

Плагин объединяет интерфейс на компонентах Grafana и backend на Go. Команды `make build`, `make test`, `make dev` и `make package` предназначены для сборки, тестирования, локальной разработки и создания пакета соответственно. Демо Grafana в Docker Compose доступно на localhost через порт `13010`.

Ответственность backend разделена по назначению: `pkg/policy` владеет схемой декларативного документа, проверкой, компиляцией и вычислением уровней и процессов; `pkg/storage` - аддитивной миграцией схемы, неизменяемыми ревизиями политики, CAS-записями и хранением процессов; `pkg/plugin` - маршрутами ресурсов в границах организации и доверенными ролью и автором; `pkg/sync` остается владельцем источника Grafana. Документ политики проверяется до сохранения, а каждая запись под управлением политики читает активную ревизию в той же транзакции SQLite, что и строки состояния и аудита.

Для загрузки неподписанной сборки используйте закрытый экземпляр Grafana для разработки. Точная настройка Grafana приведена в разделе [установки](INSTALL.md). Перед публикацией логов и тестовых данных удалите учетные данные и конфиденциальную информацию об оповещениях.

Порядок предложений и сообщений об ошибках описан в [руководстве для участников](../../CONTRIBUTING.md).
