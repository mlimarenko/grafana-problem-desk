# Работа

Откройте Problem Desk в Grafana для работы с активными firing-оповещениями Grafana Alertmanager. Первое посещение аутентифицированным пользователем запускает опрос после запуска процесса плагина. События, не замеченные во время простоя, из истории не восстанавливаются.

Эпизод определяется организацией, fingerprint и временем начала. Повторное срабатывание - отдельный эпизод со своими комментариями и подтверждениями. Восстановление фиксируется только при отсутствии эпизода в успешном полном снимке источника; сетевая ошибка не означает восстановление.

Viewer может читать рабочее пространство. Editor и Admin могут комментировать, подтверждать и отменять подтверждение, а также указывать ответственного. Admin управляет настройками и ручной синхронизацией. Данные оповещений, видимые сервисной учетной записи, доступны в рабочем пространстве организации; см. [безопасность](SECURITY.md).

Подтверждение - это запись для совместной работы, а не silence в Grafana Alerting. Оно не разрешает оповещение, не останавливает вычисление правил и не отключает уведомления автоматически. Управляйте правилами, маршрутизацией уведомлений и silences в Grafana Alerting.

## Работа с эпизодом

1. Выберите Active, Recovered или All episodes. Отфильтруйте важность или найдите хост, правило либо метку через поиск. Допускаются собственные значения severity.
2. Нажмите название проблемы, чтобы открыть подробности. URL страницы содержит ID эпизода; ссылку можно передать другому пользователю с доступом в ту же организацию.
3. Напишите в **Comment on this episode** и нажмите **Add comment**. Комментарий сохраняется как обычный текст, включая символы кода, с именем аутентифицированного пользователя Grafana и временем.
4. Нажмите **Acknowledge**, чтобы отметить, что проблема замечена. **Remove acknowledgement** отменяет отметку и создает отдельную запись в журнале действий.
5. В **Owner label** укажите логин или название команды. Это метка для совместной работы, а не создание пользователя или предоставление прав.

Обсуждение остается доступным после восстановления. У следующего срабатывания того же алерта будет отдельное обсуждение. Время отображается в часовом поясе браузера. Страницы таблицы относятся ко всей отфильтрованной выборке, а не только к загруженным строкам.
