# Contributing

Bug reports, documentation corrections and code contributions are welcome. Include the Grafana version, plugin version, steps to reproduce and relevant redacted logs in a bug report. Do not include credentials or sensitive alert data.

For changes, describe the problem and the intended behavior, keep the change focused, and run the checks described in the [development guide](docs/en/DEVELOPMENT.md). Discuss substantial changes before investing in an implementation.

Development is maintained in [GitLab](https://gitlab.piping.space/piping-space/products/grafana-problem-desk); public releases are intended for [GitHub](https://github.com/mlimarenko/grafana-problem-desk). See [SECURITY.md](SECURITY.md) for vulnerability reports.

Contributions are accepted under the [MIT License](LICENSE).
